## 1. Project Overview

This project reproduces the discovery of the antibiotic **Halicin (SU3327)** using a Directed Message Passing Neural Network (D-MPNN). To satisfy the **Parallel and Distributed Computing (PDC)** lab rubric, the pipeline scales inference to screen the massive **ChEMBL** database (2.85 million molecules) using **Apache Spark**.

### Rubric Alignment
| Criterion | Implementation |
|---|---|
| **Ingest** | Load raw SMILES from Broad Institute Repurposing Hub and ChEMBL 36 (760 MB, tab-separated) |
| **Clean / Validate** | RDKit (via Chemprop) filters invalid molecular strings; pipe-delimited SMILES split; nulls dropped |
| **Distributed Model** | PySpark **Pandas Iterator UDF** distributes PyTorch inference across CPU P-cores |
| **Results** | Score-ranked antibiotic candidates validated against known antibacterial chemotypes |

## 3. Hardware Strategy

**System:** Intel Core i7-13700H (6 P-cores / 8 E-cores, 20 threads) + RTX 4060 + 7.6 Gi RAM (WSL2).

| Phase | Device | Strategy |
|---|---|---|
| **Training** | GPU (RTX 4060) | `chemprop_train --gpu 0 --epochs 30` |
| **Inference** | CPU P-cores only | `local[4]`, `--no_cuda`, repartitioned to 16 |

### OOM Mitigations (Developed from crash debugging)
- **Driver memory** capped at `4g` (was `12g` — exceeded system RAM)
- **Executor memory** `512m` per JVM heap; Python workers use Arrow with `maxRecordsPerBatch=500`
- **Chemprop `--batch_size 100`** limits molecular graphs built per forward pass
- **48→16 partitions**: smaller per-partition batches (~6,250 molecules each) prevent OOM in `make_predictions`

### Phase 3 — Distributed Screening (`2_spark_chembl.py`)

The main deliverable. Screens ChEMBL using a **Pandas Iterator UDF**: loads the PyTorch model once per executor, streams SMILES through it in sub-batches of 100, aggregates scores.

```bash
conda activate pdc_lab
python 2_spark_chembl.py            # default: 100,000 molecules
python 2_spark_chembl.py 50000      # custom chunk
python 2_spark_chembl.py all        # full 2.85M dataset
```

#### Design Decisions

| Decision | Rationale |
|---|---|
| `if __name__ == "__main__"` guard | **Required by PySpark.** Without it, workers recursively respawn the SparkSession. |
| `os.chdir(PROJECT_DIR)` | Relative model path (`halicin_model/`) resolves regardless of CWD. |
| `JAVA_HOME = CONDA_PREFIX` | Auto-discovers JDK 17 bundled in conda env. |
| `setLogLevel("WARN")` | Suppresses verbose Spark INFO logging. |
| Runtime `CHUNK_SIZE` from `sys.argv` | Flexible: test with 10K, benchmark with 100K, full run with `all`. |
| 4× over-partitioning (16 partitions, 4 threads) | Smaller per-partition batches (~6,250 mol) prevent OOM. |
| `spark.sql.execution.arrow.maxRecordsPerBatch = 500` | Caps Arrow transfer size; avoids giant serialisation buffers. |
| `--batch_size 100` in chemprop args | Limits molecular graphs per forward pass — critical for 7.6 Gi RAM. |
| Model-load try/except in UDF | Workers return NaN gracefully instead of crashing the entire job. |
| `--no_cuda` | Keeps inference on CPU P-cores; prevents GPU VRAM contention. |
| `.cache()` + `.count()` before UDF | Materialises repartitioned DataFrame once; avoids re-scanning source. |


### Full Source: `2_spark_chembl.py`

```python
#!/usr/bin/env python
"""Phase 3: Spark Distributed Inference — Screen ChEMBL for novel antibiotics."""

import os, sys, time
from pathlib import Path
from typing import Iterator

import chemprop
import pandas as pd
from pyspark.sql import SparkSession
from pyspark.sql.functions import col, pandas_udf
from pyspark.sql.types import FloatType

PROJECT_DIR = Path(__file__).resolve().parent
os.chdir(PROJECT_DIR)
if "CONDA_PREFIX" in os.environ:
    os.environ["JAVA_HOME"] = os.environ["CONDA_PREFIX"]

P_CORE_THREADS = 4
PARTITIONS = 16
DRIVER_MEMORY = "4g"
EXECUTOR_MEMORY = "512m"
ARROW_BATCH = 500
CHEMPROP_BATCH = 100


def parse_chunk_size(arg: str):
    if arg is None:
        return 100_000
    arg = arg.strip().lower()
    if arg in ("all", "full", "-1"):
        return None
    try:
        n = int(arg)
        return n if n >= 1 else 100_000
    except ValueError:
        return 100_000


def main(chunk_size):
    t_start = time.time()
    print(f"[INFO] Chunk: {chunk_size or 'FULL 2.85M'}, "
          f"partitions: {PARTITIONS}, batch: {CHEMPROP_BATCH}")

    spark = (
        SparkSession.builder
        .appName("ChEMBL_Distributed_Antibiotic_Screening")
        .master(f"local[{P_CORE_THREADS}]")
        .config("spark.driver.memory", DRIVER_MEMORY)
        .config("spark.executor.memory", EXECUTOR_MEMORY)
        .config("spark.sql.execution.arrow.pyspark.enabled", "true")
        .config("spark.sql.execution.arrow.maxRecordsPerBatch", str(ARROW_BATCH))
        .getOrCreate()
    )
    spark.sparkContext.setLogLevel("WARN")
    print(f"[OK] Spark ready — {P_CORE_THREADS} threads, "
          f"{DRIVER_MEMORY} driver / {EXECUTOR_MEMORY} executor.")

    df_chembl = (
        spark.read.csv("chembl_36_chemreps.txt", sep="\t", header=True)
        .select(col("canonical_smiles").alias("smiles"), "chembl_id")
        .dropna()
    )
    if chunk_size is not None:
        df_chembl = df_chembl.limit(chunk_size)

    df_target = df_chembl.repartition(PARTITIONS)
    df_target.cache()
    row_count = df_target.count()
    print(f"[OK] Ingested {row_count:,} molecules "
          f"(~{row_count // PARTITIONS:,}/partition).")

    @pandas_udf(FloatType())
    def predict_antibiotic_udf(iterator: Iterator[pd.Series]) -> Iterator[pd.Series]:
        args = chemprop.args.PredictArgs().parse_args([
            "--test_path", "/dev/null", "--preds_path", "/dev/null",
            "--checkpoint_dir", "halicin_model", "--no_cuda",
            "--batch_size", str(CHEMPROP_BATCH),
        ])
        try:
            model_objects = chemprop.train.load_model(args=args)
        except Exception as exc:
            sys.stderr.write(f"[FATAL] Model load failed: {exc}\n")
            for smiles_series in iterator:
                yield pd.Series([float("nan")] * len(smiles_series))
            return

        for smiles_series in iterator:
            smiles_list = [[s] for s in smiles_series.tolist()]
            preds = chemprop.train.make_predictions(
                args=args, model_objects=model_objects, smiles=smiles_list,
            )
            results = []
            for p in preds:
                if isinstance(p, list) and len(p) > 0 and isinstance(p[0], (float, int)):
                    results.append(float(p[0]))
                else:
                    results.append(0.0)
            yield pd.Series(results)

    print("[*] Running distributed inference …")
    t_infer = time.time()
    results_df = df_target.withColumn("Antibiotic_Score", predict_antibiotic_udf(col("smiles")))
    results_df.cache()
    _ = results_df.count()
    t_infer = time.time() - t_infer
    print(f"[OK] Inference: {t_infer:.1f}s ({row_count / t_infer:.0f} mol/s)")

    print("\n┌── TOP 10 NOVEL ANTIBIOTIC CANDIDATES FROM ChEMBL ──┐")
    results_df.orderBy(col("Antibiotic_Score").desc()).limit(10).show(truncate=False)
    print("└──────────────────────────────────────────────────────┘")

    hit_count = results_df.filter(col("Antibiotic_Score") > 0.5).count()
    total = time.time() - t_start
    print(f"\nMolecules with score > 0.5: {hit_count:,}")
    print(f"Total wall-clock time: {total:.1f}s")
    spark.stop()


if __name__ == "__main__":
    chunk_arg = sys.argv[1] if len(sys.argv) > 1 else None
    main(parse_chunk_size(chunk_arg))
```

## 7. Explainer Video — Talking Points

1. "We used **PySpark** to distribute a neural network inference workload over **2.85 million ChEMBL molecules**."
2. "We hit an **OOM crash at 12 Gi driver memory** on a system with only 7.6 Gi RAM. We solved it by capping driver memory at 4 Gi, adding executor memory config, capping Arrow batch sizes, and limiting chemprop to **100 molecules per forward pass**."
3. "We over-partitioned the DataFrame **4× the thread count** so each worker processes smaller batches — preventing Out-of-Memory while keeping all cores saturated."
4. "We used an **Iterator Pandas UDF** to load the PyTorch model **once per executor**, bypassing I/O bottlenecks."
5. "The model correctly surfaced **fluoroquinolones and cephalosporins** as top hits — the exact chemotypes used against *E. coli* in the clinic."
